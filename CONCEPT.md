# Концепція проєкту: Особисте портфоліо

## 1. Тип проєкту
Особисте портфоліо розробниці.

## 2. Суть проєкту (Elevator pitch)
Сайт-візитівка для демонстрації моїх навчальних і практичних робіт у сфері вебтехнологій та програмування, призначений для потенційних роботодавців і замовників.

## 3. Цільова аудиторія
* **Хто відвідувач:** IT-рекрутери, HR-менеджери, потенційні клієнти або викладачі.
* **Яку задачу вирішує:** Швидкий огляд моїх навичок, ознайомлення з реальними проєктами та зручний зв'язок зі мною.

## 4. Список секцій сайту та їхній опис
1. **Головна (Hero-секція):** Привітання, моє ім'я, коротка роль (Junior Developer) та заклик до дії.
2. **Про мене:** Коротка інформація про мій досвід, навчання (комп'ютерні науки) та технології, якими володію.
3. **Проєкти:** Галерея або список моїх робіт (з посиланнями на репозиторії GitHub та описом технологій).
4. **Контакти:** Посилання на соціальні мережі, електронна пошта та форма зворотного зв'язку.

## 5. Референси (для натхнення)
* [GitHub Profile Portfolios](https://github.com) — для мінімалістичного стилю та структури коду.
* [Awwwards Portfolio Examples](https://www.awwwards.com) — для розуміння сучасних тенденцій вебдизайну.
