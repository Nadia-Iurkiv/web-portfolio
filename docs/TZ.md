# Технічне завдання (ТЗ)
## Проєкт: «Обмін підручниками між студентами»

### 1. Призначення
Вебплатформа для студентів для зручного обміну та передачі навчальної літератури, конспектів і підручників.

### 2. Структура сторінок (Карта сайту)
1. Головна сторінка (`/`)
2. Каталог оголошень (`/items`)
3. Сторінка деталей підручника (`/items/:id`)
4. Сторінка/форма створення нового оголошення (`/items/new`)

### 3. Функціональні вимоги
1. Перегляд списку всіх активних оголошень.
2. Пошук за назвою або автором.
3. Фільтрація за навчальною дисципліною.
4. Перегляд детальної інформації про підручник.
5. **Додавання нового оголошення з фотографією** (обов'язкова функція за варіантом №16).
6. Клієнтська та серверна валідація форми.
7. Видалення оголошення власником (CRUD).
8. Перемикач світлої та темної теми.

### 4. Нефункціональні вимоги
* Адаптивність (Mobile-First): 360px, 768px, 1280px.
* Швидкодія та SEO (Lighthouse ≥ 90).
* Доступність (a11y) за стандартами WCAG.

### 5. Стек технологій
* Фронтенд: React (Vite), React Router, Tailwind CSS.
* Бекенд: Node.js, Express REST API, JSON.
